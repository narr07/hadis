## 3. Rincian & Solusi Perbaikan Tiap Temuan

### Temuan 01 — Kontras Warna Subdued Text (HIGH / Hard Gate R-25)
- **Masalah**: Kelas `text-neutral-400` pada latar putih (`#ffffff` / `#fafafa`) hanya memiliki rasio kontras ~2.45:1. Begitu pula `dark:text-neutral-500` di latar gelap hanya ~2.87:1. Standar WCAG AA mewajibkan minimal 4.5:1 untuk teks normal.
- **Rekomendasi**: Ubah menjadi `text-neutral-600 dark:text-neutral-400` atau `text-neutral-500 dark:text-neutral-400` (rasio > 4.6:1 di kedua mode).

### Temuan 02 — Penanganan Error State Eksplisit (HIGH / Hard Gate R-27)
- **Masalah**: Di `app/pages/index.vue`, fetch API hanya mengecek `status === 'pending'` dan `displayedHadiths.length > 0`. Bila terjadi gangguan jaringan/server 500, user hanya melihat tulisan "Hadits tidak ditemukan" seolah-olah datanya nihil.
- **Rekomendasi**: Destruktur variabel `error` dan fungsi `refresh` dari `useFetch`, lalu tampilkan komponen alert/card error dengan tombol "Coba Lagi".

### Temuan 03 — Tautan Navigasi Luar Generik (HIGH / Hard Gate R-24, R-26)
- **Masalah**: Tombol GitHub di footer sidebar mengarah ke `https://github.com` (halaman beranda GitHub publik), bukan repositori atau profil pemilik.
- **Rekomendasi**: Arahkan ke profil pemilik `https://github.com/narr07` (konsisten dengan kredit `narr07` -> `permadi.dev`), atau hilangkan jika belum ada repositori publik.

### Temuan 04 — Mobile Touch Target < 44px (HIGH / Hard Gate R-03, antislop-human)
- **Masalah**: Tombol ikon copy & bookmark pada kartu hadis berukuran `size="xs"` (~24px). Pada layar sentuh smartphone, target sentuh ini rawan salah sentuh.
- **Rekomendasi**: Berikan padding sentuh ekstra atau perbesar area sentuh (`min-w-[40px] min-h-[40px]` atau `size="sm"`) saat tampilan mobile.

### Temuan 05 — Ikon Sparkle / Magic (MEDIUM / Purpose-Gate R-04)
- **Masalah**: Pada halaman baca hadis `[narrator]/[number].vue`, pemisah terjemahan menggunakan `i-lucide-sparkles`. Di aturan antislop, sparkle/bintang/magic adalah ciri khas utama visual AI generatif tanpa makna spesifik.
- **Rekomendasi**: Ganti dengan ikon yang relevan dengan konteks bahasa/kitab, misalnya `i-lucide-languages` atau `i-lucide-book-open`, atau gunakan ornamen garis tipis sederhana.

### Temuan 06 — Panah Dekoratif pada Tombol (MEDIUM / Purpose-Gate R-08)
- **Masalah**: Tombol "Lihat semua hadits Bukhari →" menyertakan karakter Unicode panah `→` yang redundant.
- **Rekomendasi**: Hapus karakter panah `→` dari label teks teks tombol.

### Temuan 07 — Tumpukan Glassmorphism (MEDIUM / Purpose-Gate R-10)
- **Masalah**: Efek `backdrop-blur-md` diterapkan di sidebar desktop, header sticky, dan banner atas halaman katalog sekaligus. Saat konten digulir, teks di bawah banner menjadi buram bertumpuk.
- **Rekomendasi**: Batasi `backdrop-blur` hanya pada header atas (1 elemen). Sidebar dan banner kartu utama gunakan latar solid `bg-white dark:bg-neutral-900`.

### Temuan 08 — Kebersihan Komentar Kode (LOW / antislop-code)
- **Masalah**: Adanya komentar naratif seperti `// Fetch Narrator list for narrator details`, `// Active list to render`, `<!-- Top Part: Brand + Navigation -->`, `<!-- Arabic Matn (Body) -->`.
- **Rekomendasi**: Hapus komentar-komentar yang sekadar menceritakan ulang apa yang sudah jelas terbaca dari nama variabel/tag kode. Pertahankan komentar yang menjelaskan keputusan arsitektural/edge cases.

### Temuan 09 — Pendokumentasian DESIGN.md (LOW / Quality Lock R-37)
- **Masalah**: Belum ada file `DESIGN.md` yang menetapkan arah visual dan batasan dial antislop proyek.
- **Rekomendasi**: Buat file `DESIGN.md` yang mencantumkan identitas, palet warna, tipografi, dan dial yang disepakati.
